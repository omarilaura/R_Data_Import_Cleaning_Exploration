# R Data Import, Exploration and Cleaning

This project demonstrates foundational data analysis skills in R using a peacebuilding dataset.

Topics covered:
- Importing and inspecting CSV data with tidyverse
- Exploring dataset dimensions, column names and data types
- Generating summary statistics
- Checking duplicate rows and missing values
- Cleaning data using `distinct()`
- Exploring individual columns and unique values

Tools: R, RStudio, tidyverse, readr and dplyr.
